# Just-In-Time

A lightweight, client-side budget justification generator built for research administrators and hosted on GitHub Pages. Upload a grant budget spreadsheet, select a template type, and receive a formatted Word document ready to submit.

## Features

- **Settings tab** — securely store a Gemini API key and manage multiple Institutional Profiles, each containing custom fringe benefit and F&A / indirect cost boilerplate text. All data is persisted in browser localStorage.
- **Generator tab** — select an Institutional Profile and grant template type (NIH Detailed, NIH Modular, NSF, or Generic), upload a budget file (.csv / .xls / .xlsx), and provide a project summary to trigger the full generation workflow.
- **AI-powered narrative** — budget data is parsed with SheetJS and sent to the Gemini API using structured JSON output mode. The schema adapts per template type (e.g., NIH Modular suppresses dollar amounts; NSF separates participant support costs).
- **Validation layer** — AI-generated dollar amounts are compared against a Source-of-Truth dictionary extracted directly from the uploaded file. Mismatches pause the workflow and surface a warning banner with an option to edit the JSON payload or force a regeneration.
- **Boilerplate injection** — fringe and F&A sections are pulled from the selected Institutional Profile in localStorage rather than generated by the AI, ensuring institutional language remains exact.
- **Word document output** — the final payload is used to build a `.docx` file from scratch using the `docx` library. No pre-built template files are required. The document downloads automatically to the user's machine.

## Tech Stack

| Concern | Library |
|---|---|
| Spreadsheet parsing | [SheetJS](https://sheetjs.com/) |
| AI narrative generation | [Gemini API](https://ai.google.dev/) (structured JSON output) |
| Word document generation | [docx](https://github.com/dolanmiu/docx) (built programmatically, no template files required) |
| Settings persistence | Browser `localStorage` |

## Local Development

No build step required. Open `index.html` directly in a browser, or serve the directory with any static file server:

```bash
npx serve .
```

## Deployment

Push to the `main` branch. GitHub Pages serves `index.html` from the repository root automatically.

## Usage

1. Go to the **Settings** tab.
2. Enter and save your Gemini API key.
3. Create at least one Institutional Profile with your institution's fringe and F&A boilerplate text.
4. Switch to the **Generator** tab.
5. Select a profile and template type, upload your budget file, and paste a project summary.
6. Click **Generate Justification** — a `.docx` file will download automatically.
